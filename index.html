Les détails

Camping éphémère

Apportez votre tente. Un camping est monté pour l'occasion — vous pouvez dormir sur place jusqu'au dimanche.

Dress code

Sortez le meilleur de votre garde-robe Coachella : franges, fleurs, paillettes, couleurs.

Ambiance

Musique, danse, lumières, et tout ce qu'il faut pour transformer le jardin en festival le temps d'une nuit.
